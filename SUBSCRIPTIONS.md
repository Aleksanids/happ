# Подписки Happ

Этот репозиторий предназначен для доставки двух списков, которые собирает и проверяет существующий Windows-сервер владельца.

- `speed.txt` — «Авто — Скорость»: проверенные узлы с сортировкой по задержке HTTPS-запросов и разбросу задержки.
- `dots.txt` — «Авто — Dots»: проверенные узлы разрешённых стран; США находятся в начале списка.
- `manifest.json` — поколение, дата проверки, срок свежести, количество узлов и контрольные суммы файлов.

Каждая подписка задаёт Happ интервал обновления один час. Серверное расписание сборки и отправки ещё не установлено; файлы этого первого кандидата являются снимком проведённой проверки. Метки времени не обновляются без новой проверки. При истечении срока свежести список нельзя считать актуальным, даже если файл продолжает скачиваться.

В текущем формате доступен ручной выбор сервера. Слово «Авто» в названии не означает проверенное автоматическое переключение: воспроизведение отдельных JSON-пунктов «Авто», подобных провайдерским подпискам Happ, остаётся отдельной проверкой. Dots-профиль задаёт сетевые выходы и не изменяет права или регион аккаунта OpenAI.

Источники — общедоступные списки [Au1rxx/free-vpn-subscriptions](https://github.com/Au1rxx/free-vpn-subscriptions), перечисленные в manifest.json. Секретные ссылки владельца, платные подписки из Happ, рабочие данные и административные учётные данные сюда не переносятся. Windows-сервер выполняет сборку и проверку; пользовательский VPN-трафик через него не проходит.

Репозиторий при подготовке кандидата закрытый. До отдельного разрешения владельца и анонимной HTTPS-проверки файлы не считаются готовыми общедоступными подписками.
